Il traite les worktrees, les verrous et les branches locales et distantes dont le contenu est déjà dans la branche par défaut (ancêtre, patchs équivalents, ou PR fusionnée dans la branche par défaut dont la tête est ce commit), en simulation par défaut ; `--appliquer` agit, `--appliquer --distant` supprime aussi les branches distantes, une par une avec un bail (`--force-with-lease`) sur le sha analysé. Doc : `docs/menage-run.md`;
